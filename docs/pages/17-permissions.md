# 权限管理：人员名单 + 高密度权限矩阵

视觉以用户提供的权限配置截图为准：蓝色下划线模式栏、左侧人员搜索、右侧类型 Tab、浅灰表头、细分隔线和锁图标。路由为 `/settings/permissions`，实现位于 `apps/web/app/settings/permissions/page.tsx`。设计稿位于 `design.pen` 的 `P11 权限管理` Light / Dark 两个画板。

```text

-------------------------------------------------------------------
```

## 布局与密度

- 左栏宽 296px，仅人员名单和即时搜索，不增加部门/角色树；行高 33px，选中项浅蓝底、蓝色左边条。
- 右栏填充剩余宽度，类型 Tab 与权限项搜索位于同一工具栏；权限行高 32px，动作列宽 94px。
- 表头吸顶，名单和矩阵独立滚动；颜色跟随 Light / Dark 语义 Token。

## 交互与真实权限

- 权限快速配置：点击锁立即保存单格个人覆盖；个人设置旁可恢复默认，顶部可二次确认后全部恢复默认。
- 用户最终权限：只读展示角色/组织/项目基线叠加个人覆盖后的结果，不提供写操作。
- 蓝色闭锁=已授权，灰色开锁=未授权；个人拒绝用红色，小圆点表示个人覆盖。图标有状态文本和键盘操作。
- 动作仅包含服务端真实支持的查看、编辑、管理；不支持的动作显示 `—`，不以 UI 虚构导出等权限。
- 人员切换后忽略前一个人员的迟到响应；保存结果不写入另一个人员的矩阵。数据仍由 NexusFlow 独立持有与判定。
- 无匹配、无成员、加载失败与权限闸门不足必须明确提示，不放入演示数据。
