NexusFlow 演示数据（demo v1）
================================

目的
----
给现有真实租户（anner / moss）补齐一整套可演示的业务数据：
项目、任务、子任务（任务分配）、里程碑、工时、冲突、派发、审批、
收件箱、提及、工具台、组织、人员与账号。

只写 NexusFlow 自己的 Postgres（nexusflow schema）与 MinIO 文件对象，
不改业务代码，也不写 Northline / Documind 的数据库。

生成 / 重放
-----------
脚本：scripts/demo-data.ts（只输出 SQL，固定 id，可重复执行）

  # 1. 读取目标租户的用户/组织/人员 id
  ssh nexusflow "sudo docker exec nexusflow-postgres psql -U nexusflow -d nexusflow -A -t \
    -c \"select json_build_object(...)\"" > /tmp/nf-lookups.json

  # 2. 生成并执行 SQL（TODAY 用服务器 UTC 日期，与 /api/home 口径一致）
  TODAY=$(ssh nexusflow 'date -u +%F') MANIFEST=/tmp/nf-manifest.json \
    bun scripts/demo-data.ts > /tmp/nf-demo.sql
  ssh nexusflow 'sudo docker exec -i nexusflow-postgres psql -U nexusflow -d nexusflow \
    -v ON_ERROR_STOP=1' < /tmp/nf-demo.sql

  # 3. 资料库文件（首次或需要补文件时，用管理员 CLI 上传）
  nexusflow files upload <文件> --category overall-report \
    --project-id <id> --scope space

幂等规则：所有记录带 data.demo='v1'，使用 sha1 派生的固定 id；
重放时覆盖同 id 记录，并删除上一轮存在、本轮已不存在的 demo 记录。
不会删除已有的真实项目/任务/文件。
